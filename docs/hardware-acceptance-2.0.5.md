# 2.0.5 真机验收步骤

此表只记录实际耳机结果。模拟测试通过不能替代下列项目。
测试时使用本次 Release 构建，避免同时运行旧版、daemon 或其他耳机控制程序。
开始前记录型号、固件、Windows 版本、蓝牙适配器和测试时间；设备地址在对外记录中脱敏。

| 项目 | 操作与通过标准 | 实际结果 |
| --- | --- | --- |
| 软件断开 | 正常连接后点击断开，等待至少两分钟并重启程序；不得自动重开控制连接。耳机自行连电脑时仍应显示控制已暂停，手动连接后恢复 | 待验证 |
| Windows 断开 | 在蓝牙设置断开，等待至少两分钟并重启程序；不得抢连。Windows 或耳机自行连回时，软件不得阻断或回切音源 | 待验证 |
| 实体关机 | 使用耳机按键关机后开机；原因不明断开应保持暂停，手动连接后恢复控制 | 待验证 |
| 软件关机 | 软件关机成功后显示等待开机；至少五秒静默。重新开机并由 Windows 建立链路后，恢复同一耳机的电量和控制 | 待验证 |
| 三种模式 | 连续执行降噪、环境音、正常模式，核对软件确认值和实际听感；不能只有刷新瞬间显示 | 待验证 |
| 耳机端操作 | 使用实体按键切换模式，观察通知立即反映；暂时漏通知时应由设置轮询兜底 | 待验证 |
| 托盘电量 | 隐藏窗口至少十分钟，观察电量更新时间持续推进；健康连接下约三十秒读数/通知，不能因托盘停止 | 待验证 |
| 短暂超时 | 出现读取延迟时确认值应保留并标注延迟；真实断连或暂停不能把历史电量显示成实时电量 | 待验证 |
| 切换耳机 | 从 A 切到 B，快速操作不得把 A 的回复显示为 B；失败后目标仍为 B，不回抢 A | 待验证 |
| 多点操作 | 切换音源、连接/断开其他设备可执行。断开当前电脑时进入暂停，断开其他设备时不误暂停当前控制 | 待验证 |
| 通话切回 | 手机通话结束后电脑系统链路保持连接时，同一耳机控制可恢复，无需重启软件，不影响音频 | 待验证 |
| 取消和退出 | 慢连接/等待中点击断开或退出，界面保持响应，等待可结束，正常退出不写入主动暂停 | 待验证 |
| 无 Qt 环境 | 在没有 Qt 开发环境的 Windows 上验证安装、启动、页面、托盘、语言、图形回退和便携启动 | 待验证 |

耳机续航对照需使用相同型号/固件、音量、编码、降噪模式、音源、距离和初始电量，
进行重复的长时间对照。记录通信次数与放电结果，未完成前不填写省电百分比。
