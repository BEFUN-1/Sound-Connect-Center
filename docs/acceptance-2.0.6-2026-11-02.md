# Sony Device Center 2.0.6 验证记录

日期：2026-11-02（Asia/Shanghai）。本地未签名 Development 版本。

## 修复范围

连接以耳机和 Windows 的实际状态为准。Windows 未连接或状态未知时，软件不主动
建立控制连接；同一耳机重新连接 Windows 后，软件跟随恢复电量和控制，不切换音源。
软件主动断开立即关闭控制，当前未变化的系统连接不会立即触发恢复；观察到系统断开
后，下次系统确认连接可以恢复。暂停及恢复资格按设备地址保存，重启软件后仍有效。

启动时尚未连接，不再误记为永久暂停；蓝牙枚举暂时失败，不再关闭仍健康的控制通道。
旧版未保存暂停原因的记录，一次性迁移为跟随系统连接。新增暂停记录保留主动断开的
约束。

统一自动连接、手动连接、断开快照中的地址大小写，修复底层已连接或已断开而页面
未更新的问题。设备卡片按地址识别当前耳机，界面区分“系统已连接，控制已暂停”、
等待系统连接及控制恢复状态。

## 本轮真实耳机验证

设备为 WH-1000XM6，Windows 11 家庭版 build 26200，Intel Wireless Bluetooth。
固件查询未返回版本，因此不填写推测的固件号。测试使用真实 Qt 界面及生产通信
路径，设置目录隔离，不改写用户的测试配置。

| 场景 | 结果 |
| --- | --- |
| Windows 已连接，旧暂停记录恢复控制 | 通过，无需先点击连接，读到真实电量 34% |
| 降噪、环境音、正常模式 | 连续 9 次切换通过，每次有耳机新查询读回确认 |
| 模式持续显示 | 每次操作后的等待期间确认值持续显示 |
| 软件主动断开 | 控制关闭，Windows 连接保留，5 秒内无额外连接尝试 |
| 软件手动恢复 | 仅恢复同一耳机，连接尝试增加 1 次，电量恢复显示 |
| 隐藏窗口后的电量更新 | 35 秒观察预算内更新，新增 1 次电量查询，托盘显示对应电量 |
| 本轮设置恢复 | 恢复该次测试开始时记录的模式与环境音参数 |

全部检查结束后，再按本轮首次读到的设置恢复为降噪模式，并通过独立的新查询确认。

早期排查曾出现一次“耳机未确认设置”。最终连续 9 次模式测试及前一次 3 次跟踪均未
复现，最终记录中的通知和新查询回复一致。本轮未因推测增加协议重试，也不宣称所有
瞬时协议错误都已消除。

独立的真实系统断开／重连监测等待了 60 秒，但没有发生实际断开事件，因此明确记录
为跳过；对应状态迁移有自动化测试覆盖。耳机实体按键、实体关机／开机、真实手机
通话和多点音频切换，本轮未做完整人工验收，不能以模拟通过替代。
