# Windows / WH-1000XM6 验证记录

日期：2026-10-19。源码基线：`0bf9822`，包含当前工作区未提交修改。
系统：Windows 11 家庭版中文版，64 位，`10.0.26200`。
前端：.NET 8 WinForms；后端：随安装包分发的 `sonyctl.exe --direct`，不使用 daemon / IPC。
耳机：WH-1000XM6，固件版本未读取。

## 已实现

- 列出耳机内部的当前连接设备、配对历史和当前播放来源。
- 切换播放源、固定/解除固定播放源、连接、断开和取消配对；按耳机报告的能力启用按钮。
- 电量、正常/降噪/通透模式、耳机关机；失败和不可用状态不使用示例数据替代。
- 关闭主窗口隐藏到托盘；托盘数字显示电量，菜单提供三种听音模式、恢复和退出。
- 登录 Windows 时启动的开关，默认关闭，开启后以托盘模式启动。
- 单实例运行，重复启动恢复原窗口；安装、升级和卸载可通过当前用户命名管道请求退出。
- NSIS EXE 安装器，内置 .NET Desktop Runtime 8.0.32，桌面/开始菜单快捷方式和卸载入口。

多点协议来自用户提供的 Sound Connect 13.3.0 APK，经 REA/JADX 静态分析确认。
证据与报文说明见 `reverse-engineering/multipoint-protocol-findings.md`、
`reverse-engineering/ncasm-protocol-findings.md` 和
`reverse-engineering/ncasm19-protocol-findings.md`。APK 未在 Android 中执行。

## 已验证

- C++ CTest：145 项，144 通过，1 项 Windows 不适用的 Unix IPC 测试跳过，0 失败。
- WinForms Release：0 警告，0 错误；`git diff --check` 通过。
- 实机读取：显示两个连接设备、一条配对历史、当前播放来源；桌面检查时电量为 61%。
- 实机控制：正常、降噪、通透分别写入后，通过另一次连接读取到相符状态；播放源固定 on/off 均取得成功回执并回读。
- XM6 使用 NCASM `0x19`，写入保留自适应降噪及灵敏度字段；能力选择和字段保留有报文测试。
- 安装后从 EXE 启动、真实界面内容、启动项开启/关闭、标题栏关闭到托盘、重复启动恢复、正常退出及 `--tray` 启动均通过 UI 自动化检查。
- 实际右键打开托盘菜单，确认正常/降噪/通透选项及电量提示，点击“打开主窗口”成功恢复。
- 安装、运行中升级、运行中卸载通过。卸载清除安装文件及注册信息，并保留额外放入的用户文件。
- 最终安装在当前用户的 `%LOCALAPPDATA%\Programs\Sony Device Center`；桌面快捷方式目标正确，自启保持关闭。
- 最终安装目录的 477 个分发文件与暂存源逐文件 SHA-256 相符。
- 修复构建工具链混用导致 EXE 无法执行的问题；构建脚本优先使用指定编译器目录中的链接器和汇编器。
- 修复蓝牙地址大小写导致前端发现设备后无法读取状态的问题；已用实际前端的大写地址完成读取。

## 验证边界

- 为避免中断用户设备连接，没有实机执行跨设备切换、连接/断开、取消配对及耳机关机；相关协议和回执处理已实现并有自动化报文测试。
- “设为默认”对应 Sony 的固定播放源功能，界面说明为当前连接期间固定；不保证耳机重启后永久保存。
- 登录启动已验证 Run 注册项和同等 `--tray` 启动行为，未为测试重新启动 Windows。
- 未在另一台没有预装 .NET 的干净 Windows 主机上测试；已验证使用安装包中的私有 Runtime 启动。
- 原始实机日志和截图可能包含设备名/地址，保留在本地 QA 目录，不放入安装器或 ZIP。
