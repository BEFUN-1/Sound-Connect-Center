# 使用指南

适用版本：Windows x64 / Sony Device Center 2.0.6，2026-11-02。

## 安装与首次连接

1. 从 [GitHub 正式发布页](https://github.com/BEFUN-1/Sound-Connect-Center/releases/tag/v2.0.6) 下载 `SonyDeviceCenter-Qt2-2.0.6-Setup.exe`，可使用同页的 `SHA256SUMS.txt` 核对文件。
2. 打开 Windows“设置 → 蓝牙和设备”，先配对并连接耳机。
3. 退出正在运行的旧版 Sony Device Center；仅关闭窗口会保留托盘进程，需要在托盘菜单选择退出。
4. 普通双击安装器，以当前用户身份安装到 `%LOCALAPPDATA%\Programs\Sony Device Center`。安装器不接受提权或自定义 `/D` 路径。不要使用“以管理员身份运行”。
5. 启动程序，打开“设备与多点”，刷新并选择目标耳机。

本次安装文件已由维护者验证并批准作为正式版发布，包尚未签名。如系统阻止运行，请先确认文件来源与校验和；不要关闭系统防护或忽略无法解释的安全提示。干净虚拟机安装、升级和卸载尚未完成本轮验收。

## 日常使用

- **概览**：查看耳机、电量与当前状态，并使用模式快捷按钮。
- **降噪控制**：在降噪、环境音与正常模式之间切换；环境音级别和人声选项由设备能力决定。
- **均衡器**：使用设备预设、调整可用频段，并保存本地预设。WH-1000XM6 使用十段布局，没有 Clear Bass。
- **音频功能**：设备支持时显示 DSEE、智能免摘、自动关闭电源等控制。未知状态不能按已关闭理解。
- **设备与多点**：选择耳机和查看设备返回的多点信息。多点音频切换仍需更多真机验收。
- **设置**：选择主题、语言和开机启动。

蓝牙命令可能需要耳机回复。操作后请等待结果；未确认或超时信息表示本次设置尚未得到确认。

## 2.0.6 的连接规则

程序保存明确选择的耳机，不会因其暂时不可用而自动换到另一副。

Windows 未连接该耳机，或暂时无法确认系统状态时，自动恢复会等待。Windows 再次确认同一耳机连接后，程序可恢复电量和控制。自动恢复不会要求切换音源。

在软件内主动断开会关闭控制通道，并在当前 Windows 连接未变化时保持暂停；重启软件也保留此状态。可手动连接恢复，或在程序观察到系统断开后，等待同一耳机重新连接 Windows。软件关机有独立的等待状态。

旧版未记录原因的暂停状态会迁移为跟随系统连接。以上规则的自动化和有限真机证据见 [2.0.6 验收记录](acceptance-2.0.6-2026-11-02.md)。

## 托盘、升级与卸载

关闭主窗口会收起到托盘，继续同步电量。双击托盘图标恢复窗口；右键菜单提供模式控制和退出。

升级或卸载前先从托盘退出程序。通过 Windows“已安装的应用”卸载；安装器与卸载器仅管理包内列出的文件，不递归删除未知文件。较早的自定义目录安装请使用其原有卸载器移除。

## 常见问题

| 现象 | 建议 |
| --- | --- |
| 找不到耳机 | 在 Windows 蓝牙设置确认已配对并连接，再刷新列表；确认型号是否在验证范围内 |
| 系统有声音，软件显示控制暂停 | 可能保留了软件主动断开状态；选择同一耳机并手动连接 |
| 状态未知或耳机未确认设置 | 等待设备回复，记录具体功能与操作；不要根据按钮外观推断已经生效 |
| 多个程序同时使用耳机 | 退出其他控制客户端后重试；当前没有跨所有进程的设备占用锁 |
| 关闭窗口后仍有进程 | 这是托盘驻留行为，使用托盘菜单退出 |
| Windows CLI 无法连接 daemon | Windows 不支持 Unix socket IPC；退出其他控制客户端后使用 `sonyctl --direct` |
